\medskip
\noindent\textbf{Notation layer hierarchy.}
Three tiers govern which font a symbol uses:
\begin{itemize}
  \item \textbf{Primitive / theoretical layer} --- Fraktur:
    $\mathfrak{I}, \mathfrak{D}, \mathfrak{B}, \mathfrak{A},
     \mathfrak{R}, \mathfrak{K}$
  \item \textbf{Operational / projection layer} --- Calligraphic:
    $\mathcal{P}, \mathcal{C}, \mathcal{R}, \mathcal{M},
     \mathcal{O}, \mathcal{U}$
  \item \textbf{Empirical / data layer} --- Bold or blackboard bold:
    $\mathbb{D},\;\mathbf{x},\;\mathbf{v},\;\mathbf{F},\;\mathbf{T}_{AB}$
\end{itemize}
