\section{Audit Scope}
% =============================================================================

This audit tracks integration of the bridge layer --- new parser sections, runtime wiring,
export artifacts, observer integration, and viewer overlay --- against the stable VSIM
language as of \textbf{v5.0.2 / VSIM\_REFERENCE.md}. Status cells and developer notes
are left blank for the implementing team to complete as tasks land. Tick checkboxes when
verified against a real run.

\begin{infobox}
  \small\sffamily
  \textbf{Legend:}\quad
  \snew\ = does not exist in current reference \quad
  \spend\ = task open \quad
  \spass\ = verified \quad
  \sfail\ = regression or blocked \quad
  \sna\ = not applicable \quad
  \stbd\ = decision pending
\end{infobox}
