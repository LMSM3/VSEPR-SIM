\section*{Scientific and Ownership Boundaries}

\begin{itemize}
  \item Signed distance is negative inside, zero on the surface, and positive
        outside. CSG is an ordered left fold: union uses minimum, intersection
        uses maximum, and subtraction uses
        \(\max(d_{\mathrm{left}},-d_{\mathrm{right}})\).
  \item A geometry replacement either validates and commits as a new revision,
        or fails without changing the object. Accepted replacement invalidates
        every downstream product.
  \item Retained snapshots are immutable historical views. They may outlive the
        live object, but cannot satisfy a request that explicitly requires the
        current geometry revision.
  \item The renderer displays accepted snapshots and acknowledgements. It does
        not author coordinates, infer missing geometry, or mutate simulation
        truth.
\end{itemize}

\section*{MolecularDB Background Constraint}

One canonical molecule identity owns one lazily created durable MolecularDB
directory. A dynamic object is not automatically a molecule. When a verified
molecular study uses a Day 91 object, its append-only evidence may reference
the object ID, geometry revision, artifact hash, coordinate frame, and
acknowledgement. No installation-time empty directory forest, formula-level
duplicate ownership, reward write, or property promotion is part of Day 91.
